# Design Innovations logo pack

## Artwork
- `logos/di-mark-black-transparent.png`: transparent production emblem used in Gmail and the website; use on light backgrounds.
- `logos/di-logo-stacked-approved.png`: exact approved stacked logo on white.
- `source/approved-concept-01.png`: unchanged original concept.

## Fonts
JetBrains Mono Regular, Medium and Bold in installable TTF and web WOFF2. Include `fonts/fonts.css` for web use. Full SIL Open Font License 1.1 is included at `fonts/OFL.txt`.

The generated logo contains custom lettering, not an embedded font. JetBrains Mono is a reusable companion font, not an exact match to that lettering. Preserve the supplied artwork instead of retyping the logo.

Font source: https://github.com/JetBrains/JetBrainsMono
Pinned revision: 19371302b95d218af43299bce79ddbddd0bc364d

## Use
Open `preview.html` for the logo/font specimen. Preserve proportions; do not stretch or add effects. PNG raster artwork only; no editable vector master is included. Reversed-white generation attempts had visible artifacts and were excluded.

The ZIP beside this folder contains the same pack. `manifest.json` records file dimensions, SHA-256 hashes and provenance. No website deployment or signature defaults are changed by this pack itself.
